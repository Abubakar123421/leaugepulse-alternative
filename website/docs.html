Invite & permissions

Get Legacy into the server with everything it needs — once.

Invite the bot with the bot and applications.commands scopes, and enable the Server Members intent in the Discord Developer Portal.

Required bot permissions

  • View Channels · Send Messages · Embed Links · Attach Files
  • Read Message History · Manage Messages (to curate reactions)
  • Manage Roles — for the 32 team roles · Manage Channels — for weekly matchup categories
Role order matters. Keep the Legacy role above all 32 team roles, or it cannot assign or remove them. This is the single most common setup mistake.
Multi-server ready. Every guild keeps its own league, season, destinations, owners, and history. One bot can serve several leagues without any crossover.

Launch a season

The clean production sequence — about 15 minutes end to end.

Run /setup with the league identity, an IANA timezone (e.g. America/New_York), and a dedicated Commissioner role — never @everyone.
Map every permanent channel with the set…channel commands (see the channel map below).
Run /destinations and fix any missing mapping or permission warning it reports.
Upload and confirm madden_team_rosters.csv with /importrosters — 32 franchises, 2,074 players.
Run /setopenteamlist after the roster import so all 32 roster cards post with full rosters.
Upload the server's 32 custom NFL emojis, then run /syncteamemojis.
Assign owners: members self-claim with /registerteam, or bulk-assign with an atomic /importmembers CSV. Repair any role hiccups with /syncmemberroles.
Upload and confirm madden_18_week_fixtures.csv with /importfixtures start_now:True — Week 1 opens with a seven-day clock.
Verify WEEK 1 MATCHUPS exists, every fixture has a channel, and each card shows both assigned owners.
Run /backup and download the file. Do this again before any risky operation.

What lands in #commissioner-audit

  • Pending registrations and their stream links
  • Schedule proposals, counters, and confirmations
  • Private dispute statements with numbered case IDs
  • Result evidence review cards and confirmation state
  • Force-win, fair-sim, and help requests — plus every ruling

Lock this channel down so only commissioners and the bot can view it — Legacy routes there, but Discord permissions stay in your hands.

Prepared snapshots in, all-or-nothing validation, private preview before anything applies.

Roster schema — first six columns required

team_id,team_abbr,team_name,player_id,player_name,position, jersey_number,overall,dev_trait,is_on_ir,contract_years_left,contract_salary

Fixture schema — all eight columns required

fixture_id,week,away_team_id,away_abbr,away_team,home_team_id,home_abbr,home_team

Import rosters first — fixture team IDs must match the roster snapshot. Duplicate IDs, duplicate weekly matchups, identical teams, or conflicts with an official result block the whole import.

Member import — Discord-ID template (preferred)

team,discord_id,twitch,youtube Chicago Bears,123456789012345678,https://twitch.tv/example, Detroit Lions,234567890123456789,,https://youtube.com/@example
  • replace mode (default) releases omitted current owners; merge keeps them
  • IDs are safest — usernames must match exactly one current member
  • Omitted teams simply stay open; completed history is always preserved
  • Every import is previewed, and only the commissioner who created the preview can confirm it

Matchup rooms

One channel per game. Owners act with reactions; everything is audited.

ReactionWhat it doesWho may use it
📅 CalendarStart a schedule proposal — type YYYY-MM-DD HH:MM within 10 minutesEither owner
🔁 CounterCounter the pending time with a replacementOpposing owner
✅ ConfirmAccept the pending schedule — or confirm the submitted resultOpposing owner
🏁 FinishSubmit the result — type away-home score and attach one screenshotEither owner
🏠 Home force winOpen a private commissioner case for a home force winHome owner
✈️ Away force winOpen a private commissioner case for an away force winAway owner
🤝 Fair simRequest a neutral fair simulationOwner or commissioner
🆘 HelpOpen a private help case in commissioner auditOwner or commissioner
🚨 Report DisputeButton — opens a written statement modal with a numbered case IDEither owner
Score order is away-home. Not winner-loser, not your-team-first. Bears @ Lions with Bears 24, Lions 10 → enter 24-10. Read the card title before typing.

Scheduling, start to finish

Owner A reacts 📅 on the matchup card and gets a 10-minute prompt.
Owner A types a future time in the league timezone — the proposal posts and is audited.
Owner B reacts ✅ to accept, or 🔁 to counter with a different time.
On acceptance the matchup shows a confirmed Discord timestamp and reminders stop.

Results & evidence

An owner reacts 🏁, then types the away-home score with one PNG/JPG/WebP screenshot attached to the same message.
The opposing owner confirms — or disputes with ⚠️ / Report Dispute.
A commissioner reviews the private evidence in /week and approves, requests more proof, forces a winner, or fair-sims.
Only the commissioner's ruling updates official records, XP, and #final-scores — exactly once.
Player submissions are never automatically official. Disputes and evidence review sit between every submission and the record book.

Commissioner dashboard

Open /week — every league decision lives on one panel.

  • Approve Submitted Score — finalizes a complete score-and-screenshot submission
  • Request More Evidence — sends the review back for additional proof
  • Send Reminder — nudges the assigned owners immediately
  • Force Win (away / home) — awards the official result without a numeric score
  • Fair Sim — records a neutral simulated outcome
  • Review Issue — opens saved cases and dispute details
  • Reopen Final — reverses standings and XP, then reopens the matchup (second confirmation required)
  • Advance Week — opens next week's channels first, then cleans up the old week

High-impact actions ask for a separate confirmation, and updates are atomic — two commissioners can never finalize the same matchup twice. Historical weeks stay viewable in /week even after their channels are gone.

Weekly lifecycle

Only the active week lives in Discord. Everything else lives in the database.

Rollover, in order

A guard locks the guild/season/week so only one rollover can run.
Legacy verifies the next imported week actually has fixtures.
The new WEEK X MATCHUPS category and channels are created.
The completed week's recap/audit workflow kicks off.
The current-week setting and new seven-day deadline are stored.
Only then is the previous week's Discord space deleted — failures stay retryable.

Reminder slots are persisted — a bot restart never causes duplicate pings. If an owner seat is empty, commissioner audit is warned instead.

Need to jump weeks? /settings current_week:11 then /createweek number:11. That's an administrative shortcut — production seasons should advance through the dashboard.

Recaps, polls & AI

Deterministic facts. Optional Gemini narrative. Zero risk to operations.

The Weekly Recap (/aiweek)

  • Upset of the Week — weaker record beats stronger, point differential breaks ties
  • Best Game — smallest margin, then highest combined score
  • Biggest Blowout — largest margin, then highest winning score
  • MVP — commissioner-entered via /weekmvp (placeholder until then)
  • Top 5 + projected AFC/NFC playoff seeds — deterministic, with simplified ties

Late results and MVP entries edit the same recap — no duplicates, ever. Per-game recaps are available with /airecap while the matchup channel still exists.

Game of the Week (/gameoftheweek)

Post one graphic per week to the polls channel; Legacy adds both teams' custom emojis as prediction votes (keycap fallback if emojis are missing). Enter the week option first so autocomplete can filter matchup IDs.

Where AI stands

  • Gemini writes prose only — league facts are computed locally
  • It never sees tokens, evidence screenshots, disputes, or secrets
  • Daily caps, single-flight requests, retry-safe on rate limits
  • If AI fails, deterministic recaps still post and the league runs on

Check readiness anytime with /aistatus; set the voice with /aisettings.

Awards & season close

Eight awards, one published summary, then a clean archive.

The eight required awards

MVP · Offensive Player of the Year · Defensive Player of the Year · Rookie of the Year · Coach of the Year · User of the Year · Best Stream · Biggest Upset.

Legacy can suggest Coach, User, and Biggest Upset from saved league facts; commissioners may override every category with /seasonaward, then approve & publish the draft via /seasonawards.

Before /season-close will run

  • Every imported matchup is final — complete, force win, or fair sim
  • All eight awards exist, and the summary is approved & published
  • The new season name is non-empty, different, and unused
  • A named champion (optional) must have participated in the season

What survives the archive

Preserved permanentlyRemoved / rotated
Official game history & decision typesActive matchup rows and prompts
Season participants & ownership historyReminder slots, pending registrations
Careers: W/L, XP, levels, championshipsActive team stats & current ownership
Published awards & archive summarySeason trade/transaction workspace
Channel destinations & server settingsOld weekly categories & team-role members

If Discord cleanup partially fails, the archive is already safe — retry with /season-cleanup. Browse any archived season later with /season-history.

Playoffs are yours to run. This release doesn't auto-seed a bracket — projections are informational, and commissioners decide the postseason with the scheduling tools.

Hosting & backups

Current production: bot-hosting.net · Python 3.12 · entry file main.py.

Environment variables

DISCORD_TOKEN=<secret> # required DATABASE_PATH=data/leaguebot.sqlite3 BACKUP_DIR=data/backups LOG_LEVEL=INFO GEMINI_API_KEY=<optional> # AI narrative GEMINI_MODEL=gemini-2.5-flash TWITCH_CLIENT_ID=<optional> # live alerts TWITCH_CLIENT_SECRET=<optional> YOUTUBE_API_KEY=<optional>

Secrets live only in the host's environment-variable manager — never in Git, Discord, screenshots, or support tickets. Rotate anything that's ever been exposed.

Safe update procedure

Run /backup and download the SQLite file off-platform.
Pause league-changing operations during the update.
Use a merge-style GitHub sync — never "replace all files".
Restart and check the console for the gateway connection and guild count.
Verify with /destinations and a read-only command like /roster.

Backup policy

  • Back up before imports, season close, syncs, hosting changes, or maintenance
  • Keep copies off-platform — the host is never the only copy
  • Never commit a database or backup to Git
  • Run exactly one bot process against one database
